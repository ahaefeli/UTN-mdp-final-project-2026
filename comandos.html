Cheat Sheet

Comandos esenciales para Django, Next.js y Node.js

npm install <paquete>

Instala dependencias en el proyecto

npm update

Actualiza los paquetes a su última versión segura permitida en el package.json

npm cache clean --force

Fuerza la limpieza de la caché de npm. Útil ante errores extraños de instalación de paquetes

npx create-next-app@latest

Genera la estructura base de un proyecto Next.js nuevo

npm run dev

Levanta el servidor de desarrollo local

npm run build

Compila y optimiza la aplicación para subirla a producción

npm run start

Levanta el servidor de producción (requiere haber ejecutado el build antes)

rmdir /s /q .next

Elimina la carpeta de caché de Next.js. Esencial cuando hay errores de compilación corrupta o los cambios no se ven reflejados

python -m venv venv

Crea un entorno virtual aislado. Obligatorio antes de instalar dependencias

venv\Scripts\activate

Activa el entorno virtual

pip install -r requirements.txt

Instala todas las dependencias listadas en el archivo

pip freeze > requirements.txt

Guarda el listado exacto de dependencias instaladas actualmente en el entorno

django-admin startproject <nombre>

Crea la estructura inicial del backend

python manage.py startapp <nombre>

Crea una aplicación/módulo nuevo dentro del proyecto principal

python manage.py makemigrations

Analiza los cambios en los modelos y prepara las instrucciones SQL

python manage.py migrate

Ejecuta las migraciones y aplica los cambios en la base de datos

python manage.py createsuperuser

Crea un administrador para entrar al panel admin nativo

python manage.py runserver

Levanta el servidor de desarrollo

python manage.py shell

Abre la consola interactiva de Python con todo el contexto de Django cargado para probar queries
